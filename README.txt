PREVIEW
1. Extract the ZIP.
2. Double-click index.html to preview it in your browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com.
2. Create a new public repository named slp-loans-website.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for GitHub Pages to publish. Your free address will look like:
   https://YOUR-USERNAME.github.io/slp-loans-website/
